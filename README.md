# Globish 1500

Windows向けの個人用単語学習アプリです。PCではインストール不要、スマートフォンではホーム画面に追加できます。

## スマートフォンに追加

公開URL: https://takagi-souhei.github.io/globish1500-pwa/

iPhoneはSafariでURLを開き、「共有」から「ホーム画面に追加」を選択します。AndroidはChromeで開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選択してください。初回はオンラインで単語データを読み込んでください。その後はアプリ画面をオフラインでも開けます。

## 起動

エクスプローラーでこのフォルダーを開き、`start.bat` をダブルクリックしてください。既定のブラウザーでアプリが開きます。

初回は語彙CSVの取得にインターネット接続が必要です。取得した単語と学習記録はブラウザーのサイトデータ（localStorage）に保存され、通常のキャッシュ削除では消えません。「Cookieとサイトデータ」や閲覧データを削除すると、学習記録も消去されます。初回取得に失敗した場合は、画面の案内に従ってCSVを選択してください。

学習記録は端末ごとにブラウザーのサイトデータ（localStorage）へ保存され、端末間では同期されません。通常のキャッシュ削除では残りますが、「サイトデータ」または「Cookieとサイトデータ」を削除すると消去されます。

## 学習機能

- 英単語から日本語訳を思い出すフラッシュカード
- 学習開始前のレベル選択（複数選択可）
- シャッフル出題の切り替え
- レベルを問わず復習リストから出題
- 回答前はカードをクリックして意味を表示し、回答後はクリックで次の単語へ
- 回答後はカードクリックで覚えた単語として記録し、次の単語へ進む
- 復習リストボタンで登録し、回答に応じた間隔で再出題
- 単語一覧の復習リストで、あとで見直す単語を確認
- 1日あたりの目標語数の設定
- レベル別検索、学習進捗の確認
- ブラウザー内への進捗保存
- ホーム画面追加とService Workerによるアプリ画面のキャッシュ

## 語彙データ

語彙データは [taisukef/globish](https://github.com/taisukef/globish) のCSV（英語・日本語訳・レベル）から取得します。同CSVはリポジトリ上でヘッダーを含む1,497行のため、アプリでは不足分を `hello`、`goodbye`、`airport`、`internet` の補助語で補い、1,500語にしています。補助語のレベルは1です。

このアプリは個人利用を想定しています。語彙データを再配布する場合は、出典リポジトリの条件を別途確認してください。
